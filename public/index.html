VybeDeFi positions

Lending, staking, LP, and reward positions

Enter a wallet and this page loads its DeFi positions, grouped into lending, staking, liquidity, and rewards, with USD value by protocol. Each protocol total is the sum of the positions under it.

Token holdings load beside those positions, with symbols filled in for the mints. Names and logos come from the token details for those mints. A free API key on Vybe is enough to start. Paid plans raise the rate limit.

Generate a free API key

Endpoints Used:

  • DeFi Positions API GET /v4/wallets/{ownerAddress}/defi-positions
  • Wallet Token Balance API GET /v4/wallets/{ownerAddress}/token-balance
  • Token Details API GET /v4/tokens/{mintAddress}
  • Token Trade History API GET /v4/trades
  • Labeled Programs API GET /v4/programs/labeled-program-accounts

  • Positions

    Open DeFi positions for the wallet, with protocol and USD value.

  • Groups

    Rows grouped into lending, staking, liquidity, and rewards.

  • Protocol USD

    USD value rolled up by protocol from the positions response.

  • Holdings

    Token balances for the same wallet, with symbols filled in.

Also answered here

What does a DeFi lookup show?

Positions grouped by protocol, plus that wallet's token holdings.

How do I get a Vybe API key?

Generate an API key on Vybe. DeFi Positions are on the Portfolio plan.

Is DeFi Positions on the free plan?

No. Only the Portfolio plan includes it, not the five standard plans.
